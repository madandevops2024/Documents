Project Setup:
====================
Always Run Commands as a "Root User"

1) Create EC2 Instance (Amazon Linux, t2.micro) for EKS Hosting
Refer: EKS Creation steps file.

2) Create EC2 Instance (Ubuntu, t2.medium) for installing Jenkins
https://www.jenkins.io/doc/book/installing/linux/#debianubuntu

3) Create a EC2 Instance (Amazon Linux, t2.micro) and install Docker
yum install docker -y
service docker start 

4) Create EC2 instance (Amazon Linux, t2.medium) to install Ansible Server
yum install ansible -y

5) Create new user: admin-user on Docker, Eks-host and Ansible servers

Ansible
useradd: admin-user
passwd admin-user (Enter)
admin

Docker
useradd: admin-user
passwd admin-user (Enter)
admin

Eks-host Server:
useradd: admin-user
passwd admin-user (Enter)
admin

6) On Ansible, create 'workloads' folder inside user account : 'admin-user'

7) On Ansible, install  java version 17:
sudo -i
sudo yum install java-17-amazon-corretto -y

8)On Ansible, add root privilages for the user 'admin-user' inside 'visudo' file:
root    ALL=(ALL:ALL) ALL
admin-user    ALL=(ALL:ALL) ALL

9)Do below changes on Ansible server only (As we need to connect from Jenkins to Ansible Server with Credentials)
vi /etc/ssh/sshd_config
Change: PasswordAuthentication yes

10)Reload sshd service on Ansible server
service sshd reload

11) On Docker Server add admin-user to docker group:
usermod -aG docker admin-user

====================================================================
13)On both Eks-host and Docker servers, switch to 'admin-user' account:
a) su - admin-user
b) Create a folder: '.ssh'
c) Create a file inside '.ssh': 'authorized_keys'

12) On Ansible server, switch to 'admin-user' account
a) su - admin-user
b) Create a folder: '.ssh'
c) Execute: ssh-keygen
d) Copy id_rsa.pub content and paste on both Docker and Eks-host servers at location:
'admin-user>.ssh/authorized_keys

e)
sudo -i
vi /etc/ansible/hosts

------------------------
[docker]
Private IP

[eks]
Private IP
------------------------

f) On Ansible Server:
1)Switch to admin-user
su - admin-user
2)ansible docker -m ping
3)ansible eks -m ping

==========================================

14)Create new node on Jenkins Server:
ansible-node
